# Contributing

FreightSight is source-available under the [Functional Source License](LICENSE) (FSL-1.1-MIT), and it is
developed by one person. Issues and questions are welcome.

- **Bugs and ideas**: open an issue and say what you expected and what happened.
- **Pull requests**: please open an issue first, so we agree on the change before you write it.
- **Your contribution** is made under the same license as the project.
- **Security problems**: do not open a public issue. Write to pierrechambet@gmail.com.

To run the checks locally, see "Development" in the README.
